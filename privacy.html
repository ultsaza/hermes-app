Privacy Policy

This policy describes how Hermes, a personal-use desktop application, handles Google user data.

Who uses the app

Hermes is used only by its developer, with the developer's own Google accounts. It is not offered to other users.

Data accessed

With the account owner's consent, Hermes may access Gmail messages and settings, Google Calendar events, Google Drive files, Google Docs, Google Sheets and Google Contacts, limited to the OAuth scopes the owner grants.

How data is used

Data is used only to perform tasks the account owner requests from the local assistant, such as searching, reading, summarizing, sending or organizing their own email and documents.

Storage

OAuth tokens are stored only on the owner's own computer with owner-only file permissions. Hermes has no server and does not store Google user data on any server controlled by the developer.

Sharing

Google user data is not sold, and it is not shared with or transferred to third parties, except for content the owner chooses to send to the AI model provider they configured in order to carry out their own request.

Google API Services User Data Policy

Hermes's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete the locally stored tokens.
